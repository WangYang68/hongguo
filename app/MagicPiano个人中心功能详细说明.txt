===================================

版本: v3.1.71

一、个人中心整体架构
==================

个人中心（UserProfile）是MagicPiano应用的用户信息管理模块，采用Tab选项卡设计，包含以下主要功能区域：

【页面结构】
-----------
┌─────────────────────────────────────┐
│         头部信息区 (Header)          │
│  - 注册时间 + VIP试用期信息          │
│  - 账号名称                          │
│  - 邀请人（如有）                    │
│  - 头像 + 邀请码                     │
└─────────────────────────────────────┘
┌─────────────────────────────────────┐
│         Tab选项卡区域                │
│  ┌──────┬──────┬──────┬──────┐     │
│  │激活  │充值  │投资  │推广  │ ... │
│  │记录  │记录  │记录  │记录  │     │
│  └──────┴──────┴──────┴──────┘     │
└─────────────────────────────────────┘

【核心组件】
-----------
1. UserProfile - 主容器（user_center.py）
2. ActiveVipPage - 激活记录页（active_vip.py）
3. RechargeRecordPage - 充值记录页（charge_record.py）
4. InvestRecordPage - 投资记录页（invest_record.py）
5. PromotionRecordPage - 推广记录页（promotion_record.py）
6. WalletPage - 钱包页（wallet.py）
7. WithdrawalListDialog - 提现记录对话框（withdraw_record.py）
8. IncomeDetailListDialog - 收支明细对话框（income_detail.py）


二、头部信息区详细说明
====================

【显示字段】
-----------
1. 📅 注册时间: YYYY-MM-DD HH:MM:SS
   - 数据来源: login_user["created_at"]
   - 多语言标签:
     * 简体中文: "📅 注册时间: "
     * 繁体中文: "📅 註冊時間: "
     * 英文: "📅 Registration Time: "

2. -赠送vip过期时间: YYYY-MM-DD HH:MM:SS（仅试用期内显示）
   - 计算方式: created_at + 10分钟
   - 多语言标签:
     * 简体中文: "-赠送vip过期时间:"
     * 繁体中文: "-贈送vip過期時間:"
     * 英文: "-Gift vip expiration time:"

3. 👤 账号名称: user@example.com
   - 数据来源: login_user["account"]
   - 多语言标签:
     * 简体中文: "👤 账号名称: "
     * 繁体中文: "👤 用戶名稱: "
     * 英文: "👤 Account Name: "

4. 🤝 邀请人: inviter_account（仅当pushUser不为空时显示）
   - 数据来源: login_user["pushUser"]
   - 多语言标签:
     * 简体中文: "🤝 邀请人: "
     * 繁体中文: "🤝 推薦人: "
     * 英文: "🤝 Push User: "

5. 邀请码：XXXXXX（可点击复制）
   - 数据来源: login_user["push_code"]
   - 多语言标签:
     * 简体中文: "邀请码："
     * 繁体中文: "邀請碼："
     * 英文: "Push Code："
   - 功能: 点击后复制到剪贴板
   - Tooltip提示: "点击后可复制" / "點擊可複製" / "Click to copy"

6. 用户头像（圆形，30x30像素）
   - 数据来源: login_user["avatar"] URL
   - 功能: 点击可更换头像
   - 样式: RoundedImageLabel圆角图片

【显示逻辑】
-----------
试用期判断逻辑：
```python
from datetime import datetime, timedelta

# 1. 获取注册时间
initial_time = self.login_user["created_at"]
dt = datetime.strptime(initial_time, "%Y-%m-%d %H:%M:%S")

# 2. 计算试用期结束时间（+10分钟）
new_dt = dt + timedelta(minutes=10)
new_time = new_dt.strftime("%Y-%m-%d %H:%M:%S")

# 3. 获取当前时间
current_time = datetime.now()
current_time_formatted = current_time.strftime("%Y-%m-%d %H:%M:%S")

# 4. 根据试用期状态显示不同内容
if current_time_formatted > new_time:
    # 已超过试用期，只显示注册时间
    user_id_label = QLabel("📅 注册时间: " + str(self.login_user["created_at"]))
else:
    # 仍在试用期内，显示注册时间和试用期结束时间
    user_id_label = QLabel(
        "📅 注册时间: " + str(self.login_user["created_at"]) + 
        "-赠送vip过期时间:" + new_time
    )
```

显示规则：
- ✅ 试用期内：显示"注册时间"和"赠送vip过期时间"
- ✅ 超过试用期：只显示"注册时间"
- ✅ 有邀请人：显示"邀请人"字段
- ✅ 无邀请人：隐藏"邀请人"字段


三、头像上传功能
===============

【触发方式】
-----------
点击头像图标 → 弹出文件选择对话框

【验证规则】
-----------
1. 文件大小限制: ≤ 1MB (1024 × 1024 bytes)
2. 文件格式限制: .png, .jpg, .jpeg, .bmp
3. 超时时间: 无明确限制（依赖requests默认超时）

【上传流程】
-----------
```
用户点击头像
  ↓
打开文件选择对话框
  ↓
用户选择图片文件
  ↓
验证文件大小（≤1MB）
  ├─ 超过 → 提示"文件大小不能超过1MB"，终止
  └─ 符合 → 继续
  ↓
验证文件格式（PNG/JPG/JPEG/BMP）
  ├─ 不符合 → 提示"请选择有效的图片文件"，终止
  └─ 符合 → 继续
  ↓
显示进度对话框"上传中..."
  ↓
调用上传API
  ↓
服务器返回结果
  ├─ 成功 → 更新本地login_user
  │         保存到QSettings
  │         发送user_avatar_signal信号
  │         下载并显示新头像
  │         提示"设置头像成功！"
  └─ 失败 → 提示错误信息
  ↓
关闭进度对话框
```

【API接口】
-----------
URL: POST http://39.107.213.164:8090/api/user/avatar/upload
请求类型: multipart/form-data
请求参数:
- file: 图片文件（二进制）
Headers:
- Authorization: {token}

响应示例（成功）:
```json
{
    "code": 200,
    "message": "上传成功",
    "data": {
        "url": "https://example.com/avatar/xxx.jpg"
    }
}
```

响应示例（失败）:
```json
{
    "code": 非200,
    "message": "错误描述"
}
```

【代码实现】
-----------
```python
def on_avatar_clicked(self):
    file_dialog = QFileDialog(self)
    file_dialog.setNameFilter("Images (*.png *.jpg *.jpeg *.bmp)")
    
    if file_dialog.exec():
        selected_files = file_dialog.selectedFiles()
        if selected_files:
            image_path = selected_files[0]
            
            # 检查文件大小
            file_size = os.path.getsize(image_path)
            if file_size > 1024 * 1024:
                QMessageBox.warning(self, "提示", "文件大小不能超过1MB")
                return
            
            # 检查文件类型
            allowed_extensions = {'.png', '.jpg', '.jpeg', '.bmp'}
            file_extension = os.path.splitext(image_path)[1].lower()
            if file_extension not in allowed_extensions:
                QMessageBox.warning(self, "提示", "请选择有效的图片文件（PNG、JPG、JPEG、BMP）")
                return
            
            # 显示进度对话框
            progress_dialog = QProgressDialog("上传中...", None, 0, 0, self)
            progress_dialog.setWindowTitle("请稍候")
            progress_dialog.setWindowModality(Qt.WindowModality.WindowModal)
            progress_dialog.setCancelButton(None)
            progress_dialog.show()
            QApplication.processEvents()
            
            try:
                with open(image_path, "rb") as image_file:
                    files = {"file": image_file}
                    response = requests.post(
                        "http://39.107.213.164:8090/api/user/avatar/upload",
                        files=files,
                        headers=global_headers
                    )
                    
                    progress_dialog.close()
                    
                    res = response.json()
                    if res.get("code") == 200:
                        # 更新本地数据
                        self.login_user["avatar"] = res.get('data')['url']
                        self.app_setting.setValue("login_user", json.dumps(self.login_user))
                        self.user_avatar_signal.emit(1)
                        
                        # 下载并显示新头像
                        response = requests.get(self.login_user.get("avatar"))
                        if response.status_code == 200:
                            pixmap = QPixmap()
                            pixmap.loadFromData(response.content)
                            self.avatar_label_image.setPixmap(pixmap)
                            self.avatar_label_image.update()
                            QMessageBox.information(self, "成功", "设置头像成功！")
                        else:
                            QMessageBox.warning(self, "提示", "头像下载失败")
                    else:
                        QMessageBox.warning(self, "上传失败", res.get("message", "未知错误"))
            
            except Exception as e:
                progress_dialog.close()
                QMessageBox.critical(self, "错误", f"上传过程中发生错误：{str(e)}")
```

【过期判断逻辑】
---------------
```python
# 获取当前时间
current_time = datetime.now()
current_time_formatted = current_time.strftime("%Y-%m-%d %H:%M:%S")

for row, item in enumerate(self.list):
    # 获取过期时间
    initial_time = item['Expire']
    dt = datetime.strptime(initial_time, "%Y-%m-%d %H:%M:%S")
    new_time = dt.strftime("%Y-%m-%d %H:%M:%S")
    
    # 判断是否过期
    if new_time < current_time_formatted:
        # 已过期，添加标记
        self.table_widget.setItem(row, 4, QTableWidgetItem("(已过期)" + str(item['Expire'])))
    else:
        # 未过期
        self.table_widget.setItem(row, 4, QTableWidgetItem(str(item['Expire'])))
```

   - API: /api/user/income/detail/list

2. 提现记录按钮
   - 功能: 打开提现记录对话框
   - 触发: WithdrawalListDialog
   - API: /api/user/withdraw/record

3. 申请提现按钮
   - 功能: 直接申请提现（无需对话框）
   - 条件: 余额 ≥ 10元
   - API: POST /api/user/withdraw/apply

【提现逻辑】
-----------
```python
def withdraw(self):
    # 检查余额
    if self.balance <= 0:
        QMessageBox.information(self, "提示", "余额不足不能提现")
        return
    
    # 最低提现金额
    if self.balance >= 10:
        url = "http://39.107.213.164:8090/api/user/withdraw/apply"
        response = requests.post(url, timeout=5, headers=global_headers)
        res = response.json()
        
        if res.get("code") == 200:
            QMessageBox.information(self, "提示", res.get("data"))
        else:
            QMessageBox.information(self, "提示", res.get("message"))
    else:
        QMessageBox.information(self, "提示", "提现最少10元")
```

提现规则：
- 最低提现金额: 10元
- 余额不足: 提示"余额不足不能提现"
- 低于10元: 提示"提现最少10元"
- 提现方式: 一次性提现全部余额

十四、注意事项
==============

【数据缓存】
-----------
1. login_user保存在QSettings中
   - Key: "login_user"
   - Value: JSON字符串
   - 更新时机: 头像上传成功后

2. 语言设置保存在QSettings中
   - Key: "lang"
   - Value: "zh-cn" / "zh-tw" / "en-us"
   - 读取时机: 页面初始化时

【网络请求】
-----------
1. 所有API请求都有5秒超时
2. 使用global_headers传递token
3. 异常处理不完善，部分页面缺少try-catch

【分页逻辑】
-----------
1. 每页默认10条记录
2. 总页数计算: math.ceil(total / page_size)
3. 无数据时总页数为0
4. 翻页时会重新调用API

【状态管理】
-----------
1. VIP状态由服务器控制
2. 客户端只负责显示
3. 过期判断在客户端进行（激活记录页面）

【UI更新】
---------
1. 头像上传使用进度对话框
2. 表格数据每次刷新都清空重建
3. 分页按钮根据当前页自动启用/禁用

【多语言支持】
-------------
1. 所有文本都支持三种语言
2. 通过QSettings读取语言设置
3. 使用if-elif判断切换语言

【安全考虑】
-----------
1. token存储在QSettings中（明文）
2. 头像上传有大小和格式限制
3. 提现有最低金额限制


十五、常见问题
==============

Q1: 为什么有些Tab没有显示？
A: 当前代码只添加了"激活记录"Tab，其他Tab可能需要手动添加或在其他版本中使用。

Q2: 如何添加其他Tab？
A: 在user_center.py的tab_widget中添加：
```python
recharge_page = RechargeRecordPage()
tab_widget.addTab(recharge_page, "充值记录")

invest_page = InvestRecordPage()
tab_widget.addTab(invest_page, "投资记录")

promotion_page = PromotionRecordPage()
tab_widget.addTab(promotion_page, "推广记录")

wallet_page = WalletPage(balance)
tab_widget.addTab(wallet_page, "钱包")
```

Q3: 头像上传失败怎么办？
A: 检查以下几点：
- 文件大小是否超过1MB
- 文件格式是否正确
- 网络连接是否正常
- token是否有效

Q4: 为什么充值记录显示"待客服确认"？
A: 充值需要人工审核，审核通过后状态会变为"已生效"。

Q5: 推广收益如何计算？
A: 推广收益 = 被邀请用户充值金额 × 收入比例

Q6: 提现多久到账？
A: 提现申请提交后需要审核，审核通过后才会打款。

Q7: 如何知道我的VIP什么时候过期？
A: 在"激活记录"Tab中查看最后一条记录的"过期时间"字段。

Q8: 可以同时有多个VIP记录吗？
A: 可以，每次激活都会创建新记录，VIP时长会累加。

Q9: 为什么收支明细中有负数？
A: 负数表示支出（提现），正数表示收入（推广收益）。

Q10: 如何修改邀请码？
A: 邀请码在注册时生成，之后不能修改。
