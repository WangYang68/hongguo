================================================================================
  一、通用说明
================================================================================

  1.1 请求格式
      - Content-Type: application/json（除文件上传外）
      - 文件上传使用 multipart/form-data

  1.2 认证方式
      - 除注册、登录、重置密码外，所有接口均需在HTTP请求头中携带:
        Authorization: <token>  （或 Token: <token>）
        Client: midi_client

  1.3 统一响应格式
      所有接口返回JSON格式如下:
      {
        "code": 200,        // 200=成功, 400=失败
        "message": "success",
        "data": {}          // 具体数据或null
      }

  1.4 分页参数说明
      带分页的接口通用查询参数:
        page  - 页码，默认1
        size  - 每页条数，默认10
        search - 搜索关键词（可选）

      分页响应格式:
        "data": {
          "total": 100,     // 总记录数
          "data": [...]     // 数据列表
        }


================================================================================
  二、认证接口（无需Token）
================================================================================

----------------------------------------------------------------------
  2.1 用户注册
----------------------------------------------------------------------

  POST /api/register

  请求体 (JSON):
  {
    "account": "user123",       // 必填，账号
    "nickname": "音乐爱好者",     // 必填，昵称，2-20个字符
    "password": "Abc@1234",     // 必填，密码，需含大小写字母+数字+特殊符号，8-20位
    "ip": "192.168.1.1",        // 可选，IP地址
    "code": "INVITE_CODE"       // 可选，邀请码（某用户的推广码push_code）
  }

  成功响应:
  {
    "code": 200,
    "message": "success",
    "data": {
      "message": "注册成功"
    }
  }

  错误示例:
  - 账号格式不正确
  - 密码必须包含大小写字母、数字和特殊符号，长度8-20位
  - 已经存在此账号
  - 不存此邀请码

----------------------------------------------------------------------
  2.2 用户登录
----------------------------------------------------------------------

  POST /api/login

  请求体 (JSON):
  {
    "account": "user123",     // 必填，账号
    "password": "Abc@1234"    // 必填，密码
  }

  成功响应:
  {
    "code": 200,
    "message": "success",
    "data": {
      "user_id": 1,
      "account": "user123",
      "nickname": "音乐爱好者",
      "token": "a1b2c3d4e5f6...",     // 32位安全随机token，后续请求需携带
      "avatar": "http://39.107.213.164:8090/uploads/avatar/xxx.png",
      "push_code": "ABCD1234",          // 用户推广码
      "money": 0,
      "status": "2",                    // "1"=VIP已过期，"2"=VIP未过期
      "created_at": "2026-01-01 00:00:00",
      "pushUser": ""                    // 邀请人账号（如有）
    }
  }

  错误示例:
  - 账号不存在
  - 密码错误
  - 账号已禁用

----------------------------------------------------------------------
  2.3 重置密码
----------------------------------------------------------------------

  POST /api/reset/pwd

  请求体 (JSON):
  {
    "account": "user123",     // 必填，账号
    "password": "NewPwd@567"  // 必填，新密码
  }

  成功响应:
  {
    "code": 200,
    "message": "success",
    "data": "重置成功请登录"
  }

  错误示例:
  - 参数错误
  - 不存在此账号

----------------------------------------------------------------------
  3.3 上传头像
----------------------------------------------------------------------

  POST /api/user/avatar/upload

  请求头:
    Authorization: <token>
    Client: midi_client

  请求体 (multipart/form-data):
    file: 头像图片文件（仅支持 .png 和 .jpg 格式）

  成功响应:
  {
    "code": 200,
    "message": "success",
    "data": {
      "url": "http://39.107.213.164:8090/uploads/avatar/xxx.png"
    }
  }

  错误示例:
  - 只允许上传png或是jpg文件
  - 文件保存失败

  说明: 上传新头像后会自动删除旧头像文件（默认头像不会被删除）

----------------------------------------------------------------------

  GET /api/user/check/vip/expire

  请求头:
    Authorization: <token>
    Client: midi_client

  成功响应 (VIP未过期):
  {
    "code": 200,
    "message": "success",
    "data": "vip未过期"
  }

  失败响应 (VIP已过期):
  {
    "code": 400,
    "message": "您的vip已经过期请充值",
    "data": null
  }


================================================================================
  四、MIDI音乐模块
================================================================================

----------------------------------------------------------------------
  4.1 上传MIDI文件
----------------------------------------------------------------------

  POST /api/upload

  请求头:
    Authorization: <token>
    Client: midi_client

  请求体 (multipart/form-data):
    file: MIDI文件（仅支持 .mid 格式）

  成功响应:
  {
    "code": 200,
    "message": "success",
    "data": {
      "url": "http://39.107.213.164:8090/uploads/xxx.mid"
    }
  }

  说明:
    - 上传成功后，服务器会异步调用AI自动翻译音乐名为英文(name_en)、
      繁体(name_ft)并打上音乐类型标签(tag)，随后入库。
    - 重名文件不允许重复上传。

  错误示例:
  - 只允许上传MID文件
  - 该midi已经存在: xxx.mid

----------------------------------------------------------------------
  4.2 音乐列表
----------------------------------------------------------------------

  GET /api/musics?page=1&size=10&search=xxx

  查询参数:
    page   - 页码（默认1）
    size   - 每页条数（默认10）
    search - 搜索关键词（可选，模糊匹配 id, name, name_en, name_ft）

  成功响应:
  {
    "code": 200,
    "message": "success",
    "data": {
      "total": 100,
      "data": [
        {
          "id": 1,
          "name": "月光奏鸣曲.mid",
          "name_en": "Moonlight Sonata",
          "name_ft": "月光奏鳴曲",
          "singer": "贝多芬",
          "path": "/uploads/xxx.mid",
          "category": "古典音乐",
          "created_at": "2026-01-01 00:00:00"
        }
      ]
    }
  }

----------------------------------------------------------------------
  4.3 删除音乐
----------------------------------------------------------------------

  GET /api/music/remove?id=1

  查询参数:
    id - 音乐ID（必填）

  成功响应:
  {
    "code": 200,
    "message": "success",
    "data": null
  }

  说明: 删除音乐时，会同时删除服务器上的文件、相关收藏记录和播放记录。

  错误示例:
  - 参数错误（ID不存在或无效）

----------------------------------------------------------------------
  4.4 编辑音乐信息
----------------------------------------------------------------------

  POST /api/music/edit

  请求体 (JSON):
  {
    "id": 1,                      // 必填，音乐ID
    "name": "月光奏鸣曲.mid",     // 可选，音乐名称
    "name_en": "Moonlight Sonata", // 可选，英文名称
    "name_ft": "月光奏鳴曲",      // 可选，繁体名称
    "singer": "贝多芬"            // 可选，歌手
  }

  成功响应:
  {
    "code": 200,
    "message": "success",
    "data": null
  }

  错误示例:
  - 参数错误
  - 数据不存在（ID无效）

  八、VIP激活码模块
================================================================================

----------------------------------------------------------------------
  8.1 激活VIP码
----------------------------------------------------------------------

  POST /api/user/activate/code

  请求头:
    Authorization: <token>
    Client: midi_client

  请求体 (JSON):
  {
    "code": "ACTIVATION_CODE"     // 必填，激活码字符串
  }

  成功响应:
  {
    "code": 200,
    "message": "success",
    "data": "激活成功"
  }

  说明:
    - 激活前会检查用户是否已有未过期的VIP
    - 如果已有有效VIP，不能重复激活
    - 激活码使用后状态会变为已使用(status=1)
    - 每个激活码同一用户只能使用一次

  错误示例:
  - 激活码不存在
  - 激活码已经激活过了
  - 已存在有效的 VIP 记录

----------------------------------------------------------------------
  8.2 VIP激活记录列表
----------------------------------------------------------------------

  GET /api/user/code/list?page=1&size=10

  查询参数:
    page - 页码（默认1）
    size - 每页条数（默认10）

  成功响应:
  {
    "code": 200,
    "message": "success",
    "data": {
      "total": 3,
      "data": [
        {
          "id": 1,
          "code": "ACTIVATION_CODE",
          "vip_day": 30,
          "expire_at": "2026-02-01 00:00:00",
          "created_at": "2026-01-01 00:00:00",
          "user_id": 1
        }
      ]
    }
  }

  说明: 该接口返回当前登录用户的VIP激活历史记录。

----------------------------------------------------------------------
  10.1 AI代码生成接口
----------------------------------------------------------------------

  POST /api/ai/code/gen

  请求头:
    Authorization: <token>
    Client: midi_client

  说明:
    - 该接口为对外提供给AI大模型使用的接口
    - 支持三种请求格式:
      1. application/json      - JSON格式
      2. application/x-www-form-urlencoded  - 表单格式
      3. multipart/form-data   - 多媒体表单格式
      4. 其他                   - 原始文本，读取body内容

  请求体:
    支持任意格式的参数，接口会接收并打印所有参数（当前为桩实现，
    仅记录参数日志，不返回有意义的数据）

  注意: 此接口目前为桩实现(stub)，仅接收参数并打印日志，
        实际功能待后续开发。
