MagicPiano 个人中心账号信息与有效期逻辑说明文档
===============================================

版本: v3.1.71
更新日期: 2026-06-18


一、用户账号信息结构
==================

login_user 对象完整结构：
------------------------
```python
{
    "token": "用户认证token",
    "nickname": "用户昵称",
    "account": "邮箱账号",
    "avatar": "头像URL地址",
    "push_code": "用户的邀请码（用于邀请他人）",
    "pushUser": "邀请人账号（谁邀请了你）",
    "created_at": "注册时间",
    "status": "用户状态",
    ...
}
```

关键字段说明：
- token: 登录凭证，用于所有需要认证的API请求
- account: 用户注册时的邮箱地址
- push_code: 系统自动生成的邀请码，用于分享给他人获得收益
- pushUser: 如果该用户是被邀请注册的，这里显示邀请人的账号
- created_at: 注册时间，格式为 "YYYY-MM-DD HH:MM:SS"
- avatar: 头像图片的URL地址


二、VIP有效期核心逻辑
====================

MagicPiano采用双层VIP验证机制：
1. 服务器端VIP检查
2. 客户端试用期检查

【机制1】服务器端VIP检查
------------------------
API接口：
- URL: GET http://39.107.213.164:8090/api/user/check/vip/expire
- Headers: Authorization: {token}
- 超时时间：5秒

响应示例（VIP有效）：
```json
{
    "code": 200,
    "message": "VIP有效"
}
```

响应示例（VIP无效）：
```json
{
    "code": 非200,
    "message": "VIP已过期或未激活"
}
```

检查时机：
- 每次点击播放按钮时
- 从暂停恢复播放时
- 自动播放下一首时

【机制2】客户端试用期检查
-------------------------
试用期规则：
- 所有新用户注册后自动获得10分钟免费试用期
- 试用期从注册时间（created_at）开始计算
- 试用期内即使没有VIP也可以播放音乐

试用期计算逻辑：
```python
from datetime import datetime, timedelta

# 1. 获取注册时间
initial_time = self.login_user["created_at"]  # 例如："2026-06-18 10:00:00"

# 2. 转换为datetime对象
dt = datetime.strptime(initial_time, "%Y-%m-%d %H:%M:%S")

# 3. 计算试用期结束时间（注册时间 + 10分钟）
new_dt = dt + timedelta(minutes=10)

# 4. 格式化回字符串
new_time = new_dt.strftime("%Y-%m-%d %H:%M:%S")  # 例如："2026-06-18 10:10:00"

# 5. 获取当前时间
current_time = datetime.now()
current_time_formatted = current_time.strftime("%Y-%m-%d %H:%M:%S")
```

【双重验证逻辑】
---------------
完整的VIP验证判断：

```python
# 调用服务器VIP检查
response = requests.get(
    "http://39.107.213.164:8090/api/user/check/vip/expire",
    headers=global_headers
)
res = response.json()

# 计算试用期
initial_time = self.login_user["created_at"]
dt = datetime.strptime(initial_time, "%Y-%m-%d %H:%M:%S")
new_dt = dt + timedelta(minutes=10)
current_time = datetime.now()

# 双重验证：必须同时满足两个条件才阻止播放
if res.get("code") != 200 and current_time > new_dt:
    # VIP无效 且 超过试用期
    显示到期提示
    弹出激活对话框
    return  # 阻止播放
else:
    # 允许播放的情况：
    # 1. VIP有效（code == 200），无论是否超过试用期
    # 2. VIP无效但在试用期内（current_time <= new_dt）
    继续播放流程
```

允许播放的条件（满足任一即可）：
1. ✅ 服务器返回 code == 200（VIP有效）
2. ✅ 当前时间在试用期内（current_time <= new_dt）

阻止播放的条件（必须同时满足）：
1. ❌ 服务器返回 code != 200（VIP无效）
2. ❌ 当前时间超过试用期（current_time > new_dt）


三、个人中心显示的有效期信息
==========================

在个人中心页面（UserProfile），会根据试用期状态显示不同信息：

【情况1】仍在试用期内
--------------------
显示内容：
```
📅 注册时间: 2026-06-18 10:00:00 -赠送vip过期时间: 2026-06-18 10:10:00
👤 账号名称: user@example.com
🤝 邀请人: inviter_account（如果有）
```

代码逻辑：
```python
if current_time_formatted > new_time:
    # 已超过试用期，只显示注册时间
    user_id_label = QLabel(user_id_label_text + str(self.login_user["created_at"]))
else:
    # 仍在试用期内，显示注册时间和试用期结束时间
    user_id_label = QLabel(
        user_id_label_text + str(self.login_user["created_at"]) + 
        user_id_label_text2 + new_time
    )
```

【情况2】已超过试用期
--------------------
显示内容：
```
📅 注册时间: 2026-06-18 10:00:00
👤 账号名称: user@example.com
🤝 邀请人: inviter_account（如果有）
```

注意：
- 超过试用期后，不再显示"赠送vip过期时间"
- 用户需要通过激活码充值VIP才能继续使用


四、VIP激活与充值方式
====================

【方式1】激活码激活
------------------
触发场景：
- 播放音乐时检测到VIP过期
- 用户在个人中心主动激活

激活流程：
1. 弹出激活对话框
2. 用户输入激活码
3. 调用激活API

API接口：
- URL: POST http://39.107.213.164:8090/api/user/activate/code
- 请求体（JSON）:
  ```json
  {
    "code": "激活码"
  }
  ```
- Headers: Authorization: {token}

响应示例（成功）：
```json
{
    "code": 200,
    "message": "激活成功"
}
```

响应示例（失败）：
```json
{
    "code": 非200,
    "message": "激活码无效或已使用"
}
```

激活成功后：
- 服务器更新用户VIP状态
- 延长VIP有效期
- 用户可以继续播放音乐

【方式2】充值购买VIP
-------------------
充值页面：
- 入口：个人中心 → 充值记录 → 我要充值
- 支持多种充值套餐

充值流程：
1. 选择充值套餐（金额和VIP天数）
2. 上传支付凭证截图
3. 提交充值申请
4. 等待客服确认

API接口：
- URL: POST http://39.107.213.164:8090/api/user/charge/apply
- 请求体（JSON）:
  ```json
  {
    "money_day": "选择的套餐",
    "screenshot": "支付凭证URL"
  }
  ```
- Headers: Authorization: {token}

充值记录查询：
- URL: GET http://39.107.213.164:8090/api/user/charge/record
- 参数: page, size
- 显示字段：ID、充值金额、VIP时长、充值时间、过期时间、状态

状态说明：
- Confirm = 1: 已生效
- Confirm = 2: 待客服确认


五、激活记录查看
==============

在个人中心可以查看所有历史激活记录：

API接口：
- URL: GET http://39.107.213.164:8090/api/user/code/list
- 参数:
  - page: 页码
  - size: 每页数量
- Headers: Authorization: {token}

响应数据结构：
```json
{
    "code": 200,
    "data": {
        "data": [
            {
                "ID": 记录ID,
                "Code": "激活码",
                "VIPDay": 30,
                "CreatedTime": "2026-06-18 10:00:00",
                "Expire": "2026-07-18 10:00:00"
            }
        ],
        "total": 总记录数
    }
}
```

显示字段：
- ID: 激活记录ID
- Code: 使用的激活码
- VIPDay: VIP天数
- CreatedTime: 激活时间
- Expire: 过期时间

过期判断逻辑：
```python
# 获取当前时间
current_time = datetime.now()
current_time_formatted = current_time.strftime("%Y-%m-%d %H:%M:%S")

# 遍历激活记录
for item in self.list:
    initial_time = item['Expire']
    dt = datetime.strptime(initial_time, "%Y-%m-%d %H:%M:%S")
    new_time = dt.strftime("%Y-%m-%d %H:%M:%S")
    
    if new_time < current_time_formatted:
        # 已过期
        显示: "(已过期)" + item['Expire']
    else:
        # 未过期
        显示: item['Expire']
```


六、投资记录与VIP赠送
===================

除了直接充值，用户还可以通过投资获得VIP时长：

投资记录查询：
- URL: GET http://39.107.213.164:8090/api/user/invest/record
- 参数: page, size
- Headers: Authorization: {token}

显示字段：
- ID: 投资记录ID
- Money: 投资金额
- Bonus: 收入比例
- VIPDay: 赠送VIP天数
- CreatedAt: 提交时间
- Expire: 过期时间
- Confirm: 状态（1=已生效，2=待客服确认）

投资特点：
- 投资一定金额可获得VIP时长赠送
- 同时获得推广收益分成
- 需要客服确认后生效


七、推广收益与VIP
================

用户可以通过邀请他人获得收益：

推广记录查询：
- URL: GET http://39.107.213.164:8090/api/user/promotion/record
- 参数: page, size
- Headers: Authorization: {token}

显示字段：
- id: 记录ID
- account: 被邀请用户账号
- income_rate: 收入比例
- invite_user_charge_money: 被邀请用户充值金额
- income_money: 你的收入（收入比例 × 充值金额）
- created_at: 推广时间

推广机制：
1. 每个用户有唯一的邀请码（push_code）
2. 新用户注册时填写邀请码
3. 邀请人与被邀请人建立关联
4. 被邀请人充值时，邀请人获得分成
5. 分成比例由系统设定

邀请人在个人中心的显示：
```python
if self.login_user["pushUser"] != "":
    # 如果有邀请人，显示邀请人账号
    user_push_account_label = QLabel(
        "🤝 邀请人: " + str(self.login_user["pushUser"])
    )
```


八、到期提示与处理
=================

【提示触发时机】
--------------
1. 播放音乐时检测到VIP过期
2. 从暂停恢复播放时检测
3. 自动播放下一首时检测

【提示内容】
-----------
有邀请人的情况：
```
您的使用时长已经到期

请联系您的邀请人：{push_user}
```

没有邀请人的情况：
```
您的使用时长已经到期

请联系您的邀请人！
```

多语言支持：
- 简体中文：您的使用时长已经到期
- 繁体中文：您的使用時長已經到期
- 英文：Your usage period has expired

【激活对话框】
-------------
对话框标题：使用时长到期

包含元素：
1. 到期提示信息（居中显示）
2. 分隔线
3. "激活账户"标题
4. 激活码输入框
   - 占位符："请输入激活码"
   - 高度：35px
5. 激活按钮
   - 文字："激活"
   - 背景色：#0078d7
   - 高度：35px

激活流程：
1. 用户输入激活码
2. 点击激活按钮
3. 调用激活API
4. 激活成功：关闭对话框，允许播放
5. 激活失败：显示错误提示，保持对话框打开


九、特殊情况处理
==============

【情况1】从未充值的用户
----------------------
特征：
- created_at 存在
- 没有任何激活记录
- 没有任何充值记录

行为：
- 注册后有10分钟试用期
- 试用期结束后无法播放
- 必须通过激活码或充值获得VIP

【情况2】VIP已过期的用户
------------------------
特征：
- 有过激活记录或充值记录
- 所有记录的Expire时间都早于当前时间
- 服务器VIP检查返回 code != 200

行为：
- 无法播放音乐
- 显示到期提示
- 需要重新激活或充值

【情况3】VIP有效的用户
----------------------
特征：
- 至少有一条未过期的激活记录或充值记录
- 服务器VIP检查返回 code == 200

行为：
- 可以正常播放音乐
- 个人中心不显示试用期信息
- 可以查看所有历史记录

【情况4】试用期内的新用户
------------------------
特征：
- created_at 时间在10分钟内
- 可能没有任何VIP记录

行为：
- 可以正常播放音乐
- 个人中心显示试用期结束时间
- 试用期结束后需要激活VIP


十、数据流转图
=============

用户注册流程：
```
用户注册
  ↓
生成用户信息（包含created_at、push_code）
  ↓
如果有邀请码，关联邀请人（设置pushUser）
  ↓
保存到数据库
  ↓
返回用户信息（包含token）
  ↓
客户端保存login_user到QSettings
  ↓
进入主界面
```

播放音乐流程：
```
用户点击播放
  ↓
调用VIP检查API
  ↓
计算试用期（created_at + 10分钟）
  ↓
判断：VIP有效 OR 在试用期内？
  ├─ 是 → 继续播放
  └─ 否 → 显示到期提示
           ↓
       弹出激活对话框
           ↓
       用户输入激活码
           ↓
       调用激活API
           ├─ 成功 → 关闭对话框，播放音乐
           └─ 失败 → 显示错误，重试
```

激活VIP流程：
```
用户输入激活码
  ↓
调用激活API
  ↓
服务器验证激活码
  ├─ 有效 → 更新用户VIP状态
  │         延长VIP有效期
  │         记录激活历史
  │         返回成功
  └─ 无效 → 返回错误信息
```


十一、注意事项
==============

1. 试用期计算基于客户端时间
   - 使用 datetime.now() 获取当前时间
   - 如果用户修改系统时间，可能绕过试用期限制
   - 但服务器VIP检查仍会生效

2. VIP检查每次都调用服务器
   - 确保VIP状态的实时性
   - 网络不好时可能影响播放体验
   - 超时时间为5秒

3. 激活码一次性使用
   - 每个激活码只能使用一次
   - 使用后失效
   - 可以在激活记录中查看历史

4. 充值需要客服确认
   - 提交充值申请后不会立即生效
   - 需要客服人工审核
   - 状态为"待客服确认"时不能使用

5. 推广收益实时计算
   - 被邀请人充值时自动计算分成
   - 分成比例由系统设定
   - 可以在推广记录中查看明细

6. 头像上传限制
   - 文件大小不超过1MB
   - 仅支持PNG、JPG、JPEG、BMP格式
   - 上传成功后立即更新显示

7. 邀请码不可修改
   - push_code 在注册时生成
   - 之后不能更改
   - 用于追踪推广关系

8. 多语言支持
   - 所有时间显示都支持三种语言
   - 提示信息根据语言设置切换
   - 时间格式保持一致（YYYY-MM-DD HH:MM:SS）


十二、常见问题
==============

Q1: 为什么我刚注册就不能播放？
A: 检查是否超过了10分钟试用期。如果超过，需要激活VIP。

Q2: 我有VIP为什么还不能播放？
A: 检查VIP是否已过期。在个人中心查看激活记录中的Expire时间。

Q3: 如何知道我的VIP什么时候过期？
A: 在个人中心查看激活记录，每条记录都有Expire字段显示过期时间。

Q4: 试用期可以延长吗？
A: 不可以。试用期固定为10分钟，从注册时间开始计算。

Q5: 激活码从哪里获得？
A: 可以通过以下方式获得：
   - 联系邀请人
   - 参与官方活动
   - 充值购买
   - 投资获得赠送

Q6: 为什么显示"请联系您的邀请人"？
A: 因为你的VIP已过期，且你是通过邀请码注册的。邀请人可能可以提供帮助。

Q7: 充值后多久生效？
A: 需要客服确认后生效。通常在提交后的工作日内处理。

Q8: 可以同时有多个VIP记录吗？
A: 可以。每次激活都会创建新的记录，VIP时长会累加。

Q9: 推广收益可以用来兑换VIP吗？
A: 具体规则请咨询客服。目前主要通过激活码和充值获得VIP。

Q10: 如何查看我邀请了哪些人？
A: 在个人中心查看推广记录，可以看到所有被你邀请的用户及其充值情况。
