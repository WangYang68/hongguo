MagicPiano 项目功能与API接口说明文档

一、用户注册功能
================

功能描述：
用户通过邮箱、昵称、密码、邀请码和邮箱验证码完成注册。

工作流程：
1. 用户在注册页面输入邮箱地址
2. 当邮箱输入框失去焦点时（editingFinished事件触发）：
   a. 系统验证邮箱格式（正则：[^@]+@[^@]+\.[^@]+）
   b. 如果格式不正确，显示错误提示并终止流程
   c. 如果格式正确，生成6位随机数字验证码（范围：100000-999999）
   d. 使用异步邮件发送器发送邮件（不阻塞UI界面）
   e. 立即显示“验证码已发送”提示（不等邮件实际送达）
   f. 自动将光标聚焦到验证码输入框
3. 用户填写完整信息：邮箱、昵称、密码、邀请码、验证码
4. 点击注册按钮时进行前端验证：
   - 所有字段必填
   - 邮箱格式验证
   - 昵称长度：2-20个字符
   - 密码长度：至少6位
   - 验证码匹配（前端对比输入的验证码与生成的随机数）
5. 验证通过后调用注册API提交数据

验证码发送机制详解：
------------------
【触发时机】
- 邮箱输入框失去焦点时（用户输入完邮箱后按Tab键或点击其他地方）
- 每次邮箱内容改变并失去焦点都会重新发送验证码
- 同一邮箱可以多次获取验证码（每次都是新的6位数）

【发送方式】
- 使用异步邮件发送器（async_email_sender）
- 后台线程发送，不阻塞主界面
- 发件人：magicpianoplayer@foxmail.com
- 主题：MagicPiano魔琴 - 注册验证码
- 邮件内容：HTML格式，包含大号橙色验证码（24px字体）
- 最大重试次数：2次
- 预计到达时间：1-2分钟

【验证码存储】
- 验证码存储在内存变量 self.random_number 中
- 不经过服务器，纯前端验证
- 程序关闭后验证码失效

【验证码验证】
- 用户点击注册按钮时进行验证
- 将用户输入的验证码转换为整数后与 self.random_number 对比
- 如果不匹配，显示“验证码错误”提示，阻止注册
- 如果匹配，继续执行注册流程

调用的API接口：
--------------
【发送邮件】（前端本地生成验证码，异步发送）
- 方式：异步邮件发送器（async_email_sender）
- 发件人：magicpianoplayer@foxmail.com
- 主题：MagicPiano魔琴 - 注册验证码
- 内容：包含6位数字验证码的HTML邮件

【注册接口】
- URL: POST http://39.107.213.164:8090/api/register
- 请求体（JSON）:
  {
    "account": "用户邮箱",
    "nickname": "用户昵称",
    "password": "用户密码",
    "code": "邀请码"
  }
- 响应示例（成功）:
  {
    "message": "success"
  }
- 响应示例（失败）:
  {
    "message": "错误信息"
  }

【注册验证码发送机制详解】
--------------------------------
触发时机：
- 用户在注册页面输入邮箱后，邮箱输入框失去焦点时触发（editingFinished事件）
- 每次邮箱内容改变并失去焦点都会重新发送新的验证码
- 同一邮箱可以多次获取验证码（每次都是新的6位数）

发送方式：
- 使用异步邮件发送器（async_email_sender）
- 后台线程发送，不阻塞主界面
- 发件人：magicpianoplayer@foxmail.com
- 主题：MagicPiano魔琴 - 注册验证码
- 邮件内容：HTML格式，包含大号橙色验证码（24px字体）
- 最大重试次数：2次
- 预计到达时间：1-2分钟
- 邮件正文提示：“验证码有效期为5分钟，请尽快使用”

验证码存储：
- 验证码存储在内存变量 self.random_number 中（6位随机数：100000-999999）
- 纯前端验证，不经过服务器
- 程序关闭后验证码失效

验证码验证流程：
1. 用户点击注册按钮
2. 前端检查所有字段是否填写（邮箱、昵称、密码、邀请码、验证码）
3. 前端验证邮箱格式、昵称长度（2-20字符）、密码长度（至少6位）
4. 将用户输入的验证码转换为整数
5. 与 self.random_number 进行对比
6. 如果不匹配：显示“你填写的验证码错误！”提示，阻止注册
7. 如果匹配：调用API进行注册

用户体验优化：
- 验证码发送后立即显示提示，不等邮件实际送达
- 自动将光标聚焦到验证码输入框，方便用户输入
- 提示用户查看收件箱（包括垃圾邮件文件夹）
- 提示预计到达时间（1-2分钟）



二、用户登录功能
================

功能描述：
用户通过邮箱和密码登录系统，获取token和用户信息。

工作流程：
1. 用户输入邮箱和密码
2. 前端验证：
   - 账号和密码必填
   - 支持手机号（11位数字）或邮箱格式
3. 调用登录API
4. 登录成功后：
   - 保存token到全局headers（Authorization字段）
   - 保存用户信息到QSettings（login_user）
   - 关闭登录对话框
   - 进入主界面

调用的API接口：
--------------
【登录接口】
- URL: POST http://39.107.213.164:8090/api/login
- 请求体（JSON）:
  {
    "account": "邮箱或手机号",
    "password": "密码"
  }
- 响应示例（成功）:
  {
    "message": "success",
    "data": {
      "token": "用户认证token",
      "nickname": "用户昵称",
      "avatar": "头像URL",
      "push_code": "邀请码",
      "created_at": "注册时间",
      ...
    }
  }
- 响应示例（失败）:
  {
    "message": "错误信息"
  }

全局Headers配置：
- Authorization: {token} （登录后设置，用于后续所有需要认证的请求）



三、音乐列表功能
================

功能描述：
展示云端音乐库，支持分页加载和搜索。

工作流程：
1. 用户进入云音乐分类
2. 系统调用API获取音乐列表
3. 支持分页加载（每页10条）
4. 支持搜索功能（自动进行简繁体转换）
5. 滚动到底部自动加载下一页
6. 双击音乐项开始播放

调用的API接口：
--------------
【云音乐列表】
- URL: GET http://39.107.213.164:8090/api/musics
- 请求参数:
  - page: 页码（从1开始）
  - size: 每页数量（默认10）
  - search: 搜索关键词（可选，使用简体中文）
- Headers: Authorization: {token}
- 响应示例:
  {
    "code": 200,
    "data": {
      "data": [
        {
          "Id": 音乐ID,
          "Name": "音乐名称（简体）",
          "NameFt": "音乐名称（繁体）",
          "NameEn": "音乐名称（英文）",
          "Singer": "歌手",
          "Path": "音乐文件路径",
          "CreatedAt": "创建时间"
        }
      ],
      "total": 总记录数
    }
  }



四、播放音乐功能
================

功能描述：
播放选中的MIDI音乐文件。

工作流程：
1. 用户在音乐列表中双击音乐项
2. 播放前检查VIP状态和有效期
3. 如果是云音乐，添加到最近播放记录
4. 开始播放音乐

调用的API接口：
--------------
【检查VIP状态】
- URL: GET http://39.107.213.164:8090/api/user/check/vip/expire
- Headers: Authorization: {token}
- 响应示例（有效）:
  {
    "code": 200
  }
- 响应示例（无效）:
  {
    "code": 非200
  }

【添加最近播放记录】
- URL: POST http://39.107.213.164:8090/api/user/recent/play
- 请求体（JSON）:
  {
    "id": 音乐ID（整数）
  }
- Headers: Authorization: {token}
- 触发时机：播放云音乐时自动调用



五、个人中心功能
================

功能描述：
展示用户个人信息、邀请码、激活记录，支持修改头像、重置密码、VIP激活和退出登录。

主要功能模块：
1. 用户信息展示
   - 头像（点击可修改）
   - 昵称
   - 邀请码（可复制）
   - 邀请人账号（如果有）

2. 激活记录
   - 查看历史激活码使用记录
   - 显示激活码、VIP时长、激活时间、过期时间

3. 修改头像
   - 点击头像选择图片文件
   - 支持格式：PNG、JPG、JPEG、BMP
   - 文件大小限制：不超过1MB
   - 上传后自动更新显示

4. 重置密码
   - 通过邮箱验证码重置密码
   - 需要输入：邮箱、新密码、验证码
   - 验证码有效期5分钟

5. VIP激活
   - 输入激活码进行VIP充值
   - 可查看激活历史记录

6. 退出登录
   - 清除本地登录信息
   - 调用服务器登出接口
   - 关闭应用程序

工作流程：
1. 用户点击头像进入个人中心
2. 显示用户基本信息
3. 可以查看激活记录
4. 可以点击头像修改头像
5. 可以进行VIP激活
6. 忘记密码时可重置密码
7. 可以退出登录

调用的API接口：
--------------
【获取激活记录列表】
- URL: GET http://39.107.213.164:8090/api/user/code/list
- 请求参数:
  - page: 页码
  - size: 每页数量
- Headers: Authorization: {token}
- 响应示例:
  {
    "code": 200,
    "data": {
      "data": [
        {
          "ID": 记录ID,
          "Code": "激活码",
          "VIPDay": VIP天数,
          "CreatedTime": "激活时间",
          "Expire": "过期时间"
        }
      ],
      "total": 总记录数
    }
  }

【激活VIP码】
- URL: POST http://39.107.213.164:8090/api/user/activate/code
- 请求体（JSON）:
  {
    "code": "激活码"
  }
- Headers: Authorization: {token}
- 响应示例（成功）:
  {
    "code": 200,
    "message": "激活成功"
  }
- 响应示例（失败）:
  {
    "code": 非200,
    "message": "错误信息"
  }

【上传头像】
- URL: POST http://39.107.213.164:8090/api/user/avatar/upload
- 请求类型: multipart/form-data
- 请求参数:
  - file: 图片文件（PNG/JPG/JPEG/BMP，最大1MB）
- Headers: Authorization: {token}
- 响应示例（成功）:
  {
    "code": 200,
    "data": {
      "url": "头像URL地址"
    }
  }
- 响应示例（失败）:
  {
    "code": 非200,
    "message": "错误信息"
  }
- 注意事项:
  * 文件大小不能超过1MB
  * 仅支持PNG、JPG、JPEG、BMP格式
  * 上传成功后会自动更新本地缓存的用户信息

【重置密码】
- URL: POST http://39.107.213.164:8090/api/reset/pwd
- 请求体（JSON）:
  {
    "account": "邮箱地址",
    "password": "新密码"
  }
- 注意：此接口不需要Authorization header
- 前置条件：需要先通过邮件获取验证码（前端验证）
- 响应示例（成功）:
  {
    "message": "success"
  }
- 响应示例（失败）:
  {
    "message": "错误信息"
  }
- 工作流程:
  1. 用户输入邮箱
  2. 系统生成6位随机验证码并发送邮件
  3. 用户输入邮箱、新密码、验证码
  4. 前端验证验证码正确性
  5. 调用API重置密码

【退出登录】
- URL: POST http://39.107.213.164:8090/api/logout
- Headers: Authorization: {token}
- 响应示例:
  {
    "code": 200
  }
- 后续操作:
  1. 清除QSettings中的login_user数据
  2. 关闭应用程序
  3. 下次启动需要重新登录

激活流程：
1. 用户输入激活码
2. 调用激活API
3. 激活成功后更新用户VIP状态
4. 可以继续播放音乐


六、注意事项
============

1. 服务器地址：http://39.107.213.164:8090
2. 所有API请求都需要在Header中携带Authorization token
3. API请求超时时间：5秒
4. VIP检查在每次播放前执行
5. 新用户有10分钟免费试用期
6. 邮箱验证码有效期为5分钟
7. 密码长度至少6位
8. 昵称长度2-20个字符
9. 注册时必须提供有效的邀请码
