MagicPiano 播放音乐功能详细说明文档
=====================================

版本: v3.1.71
更新日期: 2026-06-18


一、播放音乐核心流程
==================

功能描述：
播放MIDI音乐文件，支持播放控制、速度调节、轨道选择、VIP验证等功能。

完整播放流程：
--------------

【步骤1】用户触发播放
触发方式：
- 双击音乐列表中的音乐项
- 点击播放按钮
- 使用快捷键 Shift+F9
- 自动播放下一首（顺序/随机模式）

【步骤2】VIP权限检查
- 调用API检查用户VIP状态和有效期
- API: GET http://39.107.213.164:8090/api/user/check/vip/expire
- Headers: Authorization: {token}

检查逻辑：
1. 获取用户注册时间（created_at）
2. 计算试用期结束时间 = 注册时间 + 10分钟
3. 获取当前时间
4. 判断条件：
   - 如果VIP检查返回code != 200 且 当前时间 > 试用期结束时间
   - 则显示"使用时长已到期"提示
   - 弹出激活码输入对话框
   - 阻止播放

新用户特权：
- 所有新用户有10分钟免费试用期
- 试用期内无需VIP即可播放
- 试用期过后必须激活VIP才能继续播放

【步骤3】音乐路径验证
- 检查 currentMusic 对象中是否包含 music_path
- 如果没有音乐路径，直接返回，不执行播放

【步骤4】播放状态判断与处理
系统根据当前音乐的 play 状态值执行不同操作：

状态值说明：
- play = 0: 未播放（初始状态）
- play = 1: 正在播放
- play = 2: 暂停状态

情况A：从暂停恢复播放（play == 2）
----------------------------------
操作流程：
1. 将状态改为播放中：currentMusic['play'] = 1
2. 更新播放按钮图标为"停止"图标（表示正在播放）
3. 调用 midiCtx.resume() 恢复播放
4. 返回，不重新加载音乐

情况B：暂停正在播放的音乐（play == 1）
--------------------------------------
操作流程：
1. 将状态改为暂停：currentMusic['play'] = 2
2. 更新播放按钮图标为"播放"图标（表示可以继续播放）
3. 调用 midiCtx.pause() 暂停播放
4. 返回，保持音乐在内存中

情况C：开始播放新音乐（play == 0）
----------------------------------
操作流程：
1. 将状态改为播放中：currentMusic['play'] = 1
2. 更新播放按钮图标为"停止"图标
3. 继续执行后续步骤（轨道选择、最近播放记录等）

【步骤5】添加最近播放记录（仅云音乐）
触发条件：
- 当前播放状态为播放中（play == 1）
- 当前分类为"云音乐"

API调用：
- URL: POST http://39.107.213.164:8090/api/user/recent/play
- 请求体（JSON）:
  {
    "id": 音乐ID（整数）
  }
- Headers: Authorization: {token}
- 超时时间：5秒

注意：本地音乐不会添加到最近播放记录

【步骤6】轨道选择处理
轨道锁定机制：
系统支持两种轨道选择模式：

模式1：锁定状态（track_lock_state = True）
- 如果设置了 locked_track，使用该锁定轨道
- 将轨道信息添加到 currentMusic['track']
- 即使切换音乐，也始终使用锁定的轨道
- 打印日志："轨道锁定状态: 使用锁定轨道 {轨道号}"

- 如果处于锁定状态但未设置 locked_track
- 移除 currentMusic 中的 track 字段
- 播放所有轨道
- 打印日志："轨道锁定状态: 但未设置锁定轨道，播放所有轨道"

模式2：解锁状态（track_lock_state = False）
- 如果 track_index == 0（全轨道模式）
  * 移除 currentMusic 中的 track 字段
  * 播放所有轨道
  * 打印日志："轨道解锁状态: 播放所有轨道"

- 如果 track_index != 0（指定轨道）
  * 将当前选择的轨道号添加到 currentMusic['track']
  * 打印日志："轨道解锁状态: 使用当前选择轨道 {轨道号}"

轨道数据格式：
- 轨道号以字符串形式存储：str(track_number)
- 例如："1", "2", "3" 等

【步骤7】停止当前播放并应用新设置
- 调用 midiCtx.stop() 停止当前MIDI播放
- 清除之前的播放上下文
- 准备加载新的音乐或应用新的轨道设置

【步骤8】将音乐任务放入队列
- 调用 task_queue.put(self.currentMusic)
- 后台MIDI播放线程从队列获取任务
- 开始实际的音乐播放

【步骤9】后台播放处理
播放线程工作流程：
1. 从任务队列获取音乐信息
2. 根据音乐路径加载MIDI文件
3. 应用转调设置（如果有）
4. 应用速度设置（speed参数）
5. 应用轨道过滤（如果指定了track）
6. 遍历MIDI消息并播放
7. 实时计算并发送播放进度
8. 处理音符事件（note_on/note_off）
9. 通过Lyre对象模拟按键


二、播放控制功能
================

1. 播放/暂停切换
----------------
触发方式：
- 点击播放按钮
- 快捷键：Shift+F9

状态转换：
- 播放中（play=1）→ 点击 → 暂停（play=2）
- 暂停（play=2）→ 点击 → 恢复播放（play=1）
- 未播放（play=0）→ 点击 → 开始播放（play=1）

按钮图标变化：
- 播放中：显示"停止"图标（stop.png）
- 暂停：显示"播放"图标（play.png）
- 悬停时：显示激活状态图标（*_active.png）

2. 上一首/下一首
----------------
触发方式：
- 点击上一首/下一首按钮
- 快捷键：Shift+F10（上一首）、Shift+F11（下一首）

上一首逻辑（play_prev_music）：
1. 停止自动播放定时器
2. 检查当前分类是否为有效音乐分类
3. 调用 table.load_prev_music() 获取上一首音乐
4. 如果是新音乐（路径不同）：
   - 重置速度为1.0
   - 更新速度下拉框显示"1.0"
   - 启用调速按钮
5. 更新 currentMusic 对象
6. 将新音乐放入任务队列

下一首逻辑（play_next_music）：
1. 停止自动播放定时器
2. 检查是否为最后一首音乐
3. 如果是最后一首：
   - 尝试加载下一页
   - 如果没有更多页面，跳转到第一页
   - 获取第一首音乐
4. 如果不是最后一首：
   - 调用 table.load_next_music()
5. 如果是新音乐（路径不同）：
   - 重置速度为1.0
   - 更新速度下拉框显示"1.0"
   - 启用调速按钮
6. 强制设置 play = 1（播放中状态）
7. 将新音乐放入任务队列

分页处理：
- 当到达最后一页最后一首时，自动循环到第一页
- 当在第一页第一首时，按上一首会跳到最后一页

3. 停止播放
-----------
触发方式：
- 切换到其他分类
- 关闭应用程序
- 手动停止

停止逻辑（stop_music）：
1. 检查是否在播放状态（play != 0 且有音乐路径）
2. 将状态设置为未播放：play = 0
3. 启用调速按钮
4. 更新按钮图标
5. 设置 Lyre 对象的 isWaitForSignal = True（停止信号等待）
6. 调用 midiCtx.stop() 停止MIDI播放

彻底停止（stop_music_after_play）：
- 用于播放完成后的清理
- 将状态设置为 play = 2
- 完全停止MIDI上下文


三、速度调节功能
================

速度范围：
- 最小速度：0.5x
- 最大速度：2.0x
- 步长：0.1x
- 默认速度：1.0x

可用速度选项：
0.5, 0.6, 0.7, 0.8, 0.9, 1.0, 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 1.7, 1.8, 1.9, 2.0

1. 下拉框选择速度
-----------------
触发方式：
- 从速度下拉框选择倍速

处理流程（on_combo_changed）：
1. 获取用户选择的速度值
2. 更新 currentMusic['speed'] = 速度值
3. 检查是否有正在播放的MIDI上下文（midiCtx）
4. 如果正在播放：
   a. 暂停播放：midiCtx.pause()
   b. 更新按钮图标为"播放"
   c. 设置状态为暂停：play = 2
   d. 应用新速度：midiCtx.set_speed(speed)
   e. 恢复播放：midiCtx.resume()
   f. 更新按钮图标为"停止"
   g. 设置状态为播放：play = 1
5. 如果未播放：
   - 仅更新 currentMusic['speed']
6. 更新调速按钮状态：
   - 如果速度 > 0.5，启用减速按钮（◀）
   - 如果速度 < 2.0，启用加速按钮（▶）

2. 左右按钮调速
---------------
触发方式：
- 点击 ◀ 按钮：减速0.1
- 点击 ▶ 按钮：加速0.1
- 快捷键：Shift+Left（减速）、Shift+Right（加速）

减速逻辑（adjust_speed(-0.1)）：
1. 获取当前速度
2. 新速度 = 当前速度 - 0.1
3. 如果新速度 >= 0.5：
   - 更新下拉框显示新速度
   - 触发 on_combo_changed 应用速度
4. 如果当前速度 <= 0.5：
   - 禁用减速按钮

加速逻辑（adjust_speed(+0.1)）：
1. 获取当前速度
2. 新速度 = 当前速度 + 0.1
3. 如果新速度 <= 2.0：
   - 更新下拉框显示新速度
   - 触发 on_combo_changed 应用速度
4. 如果当前速度 >= 2.0：
   - 禁用加速按钮

3. 速度重置规则
---------------
以下情况会自动重置速度为1.0：
- 切换到新音乐（音乐路径改变）
- 播放上一首（如果是不同的音乐）
- 播放下一首（如果是不同的音乐）

判断逻辑：
```python
old_path = self.currentMusic.get("music_path")
new_path = next_music.get("music_path")
if old_path != new_path:
    next_music['speed'] = 1.0
    self.combo.setCurrentText("1.0")
    self.on_combo_changed(self.combo.currentIndex())
```

目的：确保每首新音乐都从正常速度开始播放


四、播放模式
============

支持的播放模式：
1. 单首播放（one_play）
   - 播放完当前音乐后停止
   - 不自动播放下一首

2. 顺序播放（order_play）
   - 按列表顺序播放
   - 播放完当前音乐后自动播放下一首
   - 到达最后一首后循环到第一首

3. 随机播放（rand_play）
   - 随机选择下一首音乐
   - 可能重复播放同一首

4. 单曲循环
   - 重复播放当前音乐
   - 播放完后重新开始

模式切换：
- 点击播放模式按钮切换
- 按钮图标会根据当前模式变化
- 工具提示显示下一个模式

自动播放机制：
- 仅在顺序播放和随机播放模式下生效
- 使用 auto_next_timer 定时器
- 音乐播放完成后触发下一首
- 可以手动停止自动播放（can_auto_play = False）


五、轨道选择功能
================

轨道概念：
- MIDI文件可以包含多个音轨（Track）
- 每个音轨包含不同的乐器或声部
- 用户可以选择播放特定音轨或全部音轨

1. 轨道索引（track_index）
--------------------------
- track_index = 0: 播放所有轨道
- track_index = 1, 2, 3...: 播放指定轨道

2. 轨道锁定机制
---------------
锁定状态（track_lock_state = True）：
- 用户点击锁定按钮进入锁定状态
- 设置 locked_track 变量保存锁定的轨道号
- 之后播放任何音乐都使用锁定的轨道
- 适合只想听某个特定乐器声部的场景

解锁状态（track_lock_state = False）：
- 用户可以自由选择轨道
- 每次选择音乐时使用当前选中的轨道
- 或者选择播放所有轨道（track_index = 0）

3. 轨道切换UI
-------------
- 单音模式按钮：切换轨道显示
- 锁定按钮：锁定/解锁当前轨道
- 轨道列表：显示可用的轨道选项

4. 轨道数据处理
---------------
轨道信息存储在 currentMusic 字典中：
- 播放所有轨道：不包含 'track' 键
- 播放指定轨道：currentMusic['track'] = "轨道号"（字符串）

示例：
```python
# 播放所有轨道
currentMusic = {'music_path': '...', 'speed': 1.0}

# 播放轨道2
currentMusic = {'music_path': '...', 'speed': 1.0, 'track': '2'}
```


六、转调功能
============

功能说明：
- 支持对MIDI音乐进行升调或降调
- 转调范围：-12 到 +12（一个八度）
- 默认转调：0（原调）

触发方式：
- 快捷键：Shift+Up（升调）、Shift+Down（降调）
- 每次调整1个半音

处理流程（adjust_transposition）：
1. 获取当前转调值
2. 增加或减少1
3. 限制在 -12 到 +12 范围内
4. 更新 currentMusic['transposition']
5. 如果正在播放，重新加载音乐并应用新转调

转调原理：
- 修改MIDI文件中所有音符的音高值
- note_on 和 note_off 消息的 note 值都会调整
- 保持节奏和时长不变


七、长按/短按模式
=================

功能说明：
- 控制音符的按压时长
- 影响游戏中的按键模拟效果

触发方式：
- 快捷键：Shift+P 或 Shift+F8
- 点击界面上的模式切换按钮

模式类型：
1. 短按模式（默认）
   - 音符按下后立即释放
   - 适合快节奏音乐

2. 长按模式
   - 音符按下后保持一段时间
   - 适合需要延音的音乐

实现机制：
- 通过 press_mode_toggle 对象管理
- 影响 Lyre 对象的 playNote 和 offNote 调用时机


八、播放进度显示
================

进度计算：
1. 获取MIDI文件总时长（midiCtx.length）
2. 记录开始播放时间（start_real_time）
3. 累计暂停时间（total_paused_time_custome）
4. 计算虚拟播放时间：
   virtual_playback_time = 当前时间 - 开始时间 - 暂停时间

进度格式：
- 显示格式：MM:SS / MM:SS
- 示例：02:35 / 05:30
- 实时更新（每次处理MIDI消息时更新）

进度更新频率：
- 每次处理MIDI消息时更新
- 包括 note_on、note_off 和其他控制消息
- 通过 music_time 信号发送到UI

暂停时间累计：
- 每次调用 pause() 时记录暂停开始时间
- 每次调用 resume() 时计算暂停时长并累加
- 确保进度显示准确反映实际播放时长


九、VIP检查详细机制
===================

检查时机：
- 每次点击播放按钮时
- 自动播放下一首时
- 从暂停恢复播放时

检查流程：
1. 发送GET请求到VIP检查接口
2. 获取响应结果
3. 获取用户注册时间（login_user["created_at"]）
4. 计算试用期结束时间：
   - 将注册时间字符串转换为datetime对象
   - 添加10分钟：new_dt = dt + timedelta(minutes=10)
   - 格式化回字符串

5. 获取当前时间：current_time = datetime.now()

6. 判断逻辑：
   if res.get("code") != 200 and current_time > new_dt:
       # VIP无效且超过试用期
       显示到期提示
       弹出激活对话框
       return  # 阻止播放

特殊情况：
- 如果 res.get("code") == 200：VIP有效，允许播放
- 如果 current_time <= new_dt：在试用期内，允许播放
- 只有两者都不满足时才阻止播放

到期提示内容：
- 如果有邀请人：
  "您的使用时长已经到期
  
  请联系您的邀请人：{push_user}"
  
- 如果没有邀请人：
  "您的使用时长已经到期
  
  请联系您的邀请人！"

激活对话框：
- 标题："使用时长到期"
- 包含激活码输入框
- 包含激活按钮
- 激活成功后关闭对话框并允许播放


十、错误处理
============

1. 音乐路径不存在
- 检查：if not self.currentMusic.get("music_path")
- 处理：直接return，不执行播放

2. VIP检查失败
- 网络错误：显示连接失败提示
- 超时：5秒超时，显示错误信息
- 服务器错误：显示服务器返回的错误消息

3. MIDI文件加载失败
- 文件损坏：显示"文件格式错误"
- 文件不存在：显示"文件未找到"
- 权限问题：显示"无法访问文件"

4. 播放过程中的异常
- MIDI解析错误：跳过错误消息，继续播放
- 音频设备错误：显示"音频设备不可用"
- 内存不足：停止播放，释放资源

5. 最近播放记录添加失败
- 不影响主播放流程
- 仅在后台记录错误日志
- 不向用户显示错误提示


十一、热键汇总
==============

播放控制：
- Shift+F9: 播放/暂停
- Shift+F10: 上一首
- Shift+F11: 下一首

速度调节：
- Shift+Left: 减速0.1
- Shift+Right: 加速0.1

转调：
- Shift+Up: 升调1个半音
- Shift+Down: 降调1个半音

其他：
- Shift+P 或 Shift+F8: 切换长按/短按模式
- Shift+Insert: 收藏音乐
- Shift+Delete: 删除音乐
- Shift+PageUp: 上一页
- Shift+PageDown: 下一页


十二、数据结构
==============

currentMusic 对象结构：
```python
{
    'id': 音乐ID,
    'music_name': 音乐名称,
    'origin_name': 原始名称,
    'music_path': 音乐文件路径,
    'play': 播放状态 (0=未播放, 1=播放中, 2=暂停),
    'speed': 播放速度 (0.5-2.0),
    'track': 轨道号 (可选，字符串格式),
    'transposition': 转调值 (可选，-12到+12),
    'type': 音乐类型 (可选)
}
```

播放状态流转：
```
未播放(0) --点击播放--> 播放中(1)
播放中(1) --点击暂停--> 暂停(2)
暂停(2)   --点击恢复--> 播放中(1)
播放中(1) --播放完成--> 未播放(0) 或 下一首
```


十三、注意事项
==============

1. 播放前必须进行VIP检查
2. 新用户有10分钟免费试用期
3. 切换音乐时自动重置速度为1.0
4. 只有云音乐会添加到最近播放记录
5. 轨道锁定状态下，所有音乐使用同一轨道
6. 调速时会暂停-设置速度-恢复播放
7. 播放进度会扣除暂停时间
8. 播放模式影响自动播放行为
9. 转调和轨道选择在下次播放时生效
10. 所有API请求超时时间为5秒
